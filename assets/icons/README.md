# Idiom Custom PNG Icons

این پوشه برای قرار دادن فایل‌های آیکون PNG دست‌ساز و سفارشی کاربر در بخش «دنیای اصطلاحات» طراحی شده است.

### نام‌گذاری دقیق و مورد نیاز فایل‌ها:
1. `idiom-everyday.png`  ← آیکون دسته «روزمره» (Everyday Idioms)
2. `idiom-feelings.png`  ← آیکون دسته «احساسات» (Feelings Idioms)
3. `idiom-effort.png`    ← آیکون دسته «کار و تلاش» (Work & Effort Idioms)
4. `idiom-behavior.png`  ← آیکون دسته «رفتار و آداب» (Behavior & Manners Idioms)

### مشخصات توصیه‌شده:
- **فرمت:** PNG شفاف (Transparent Background)
- **ابعاد:** ابعاد مربعی مانند 128x128 یا 256x256 یا 512x512 پیکسل (نمایش در کانتینر 52x52 پیکسل با حفظ نسبت ابعاد و فیلتر سایه هماهنگ).
- **مسیر درون پروژه:** `assets/icons/`

# لغت‌یار — راهنمای کار با VS Code 🧠

خوش اومدی شریک! این پوشه نسخه چندفایلی پروژه لغت‌یار (v2.16.2) ـه — همون اپ دقیق، ولی مرتب‌شده برای کار دستی با هوش مصنوعی.

## ساختار پروژه

```
loghatyar-vscode/
├── index.html        ← مارکاپ صفحات (۷ صفحه + ناوبری + توست)
├── css/
│   └── style.css     ← کل استایل‌ها (~۱۶۰۰ خط: رنگ‌ها، انیمیشن‌ها، فونت‌ها)
├── js/
│   └── app.js        ← کل منطق (دیتای ۴۰۰ لغت + ۲۰ اصطلاح، SRS، کوئیز، تنظیمات)
├── build.py          ← تبدیل همه به تک‌فایل نهایی
└── dist/             ← خروجی build.py اینجا ساخته می‌شه
```

## شروع کار (۵ دقیقه)

1. **VS Code** رو نصب کن (رایگان: code.visualstudio.com)
2. `File > Open Folder` و این پوشه رو باز کن
3. افزونه **Live Server** رو نصب کن (از تب Extensions)
4. روی `index.html` راست‌کلیک → **Open with Live Server**
5. اپ توی مرورگر باز می‌شه و با هر ذخیره (Ctrl+S) خودش رفرش می‌شه ⚡

## قوانین طلایی کار با AI 🏆

- **تکه‌های کوچیک بفرست:** فقط همون ۲۰-۱۰۰ خط مربوطه رو برای AI بفرست، نه کل فایل رو. مثلاً: «این قانون CSS رو عوض کن» یا «فقط این تابع رو بهبود بده».
- **بازنویسی کل ممنوع:** به AI هیچ‌وقت نگو «کل فایل رو بده» — بگو «چی رو با چی جایگزین کنم».
- **به متن‌های عجیب‌غریب طولانی دست نزن:** اون رشته‌های base64 تصاویر و فونت‌های اپ‌ان؛ اگه پاک بشن، آیکون‌ها و فونت می‌میرن.
- **پشتیبان قبل از تغییر بزرگ:** یک کپی از پوشه بگیر (مثلاً `loghatyar-vscode-backup`).
- **بعد از هر تغییر: ذخیره → نگاه → تست.**

## ساخت نسخه نهایی (برای بات تلگرام / APK)

وقتی تغییراتت تموم شد و خواستی نسخه تک‌فایلی بگیری:

```bash
python build.py
```

فایل `dist/index.html` ساخته می‌شه — دقیقاً همون چیزی که بات تلگرام می‌خواد. (اگه پایتون نداری، از python.org نصبش کن؛ فقط همین یک بار.)

## نقشه فایل‌ها (کجا چی پیدا می‌شه؟)

| دنبال چی می‌گردی؟ | کجاست؟ |
|---|---|
| رنگ‌ها و استایل کاشی‌ها/بنرها | `style.css` — سرچ کن `.tile-quiz` یا `.idioms-banner` |
| انیمیشن‌ها | `style.css` — سرچ کن `@keyframes` یا `transition` |
| متن‌ها و اسم‌ها (مثل «چالش») | `index.html` |
| لغت‌ها و معنی‌ها | `app.js` — ابتدای فایل، آبجکت `CATEGORIES` |
| منطق مرور SRS | `app.js` — سرچ کن `dueWords` |
| منطق کوئیز | `app.js` — سرچ کن `buildQuiz` |
| تنظیمات و یادآور | `app.js` — سرچ کن `syncReminderUI` |
| شماره نسخه | `index.html` — سرچ کن `v2.16.2` (۳ جا) |
